Equations

Duty Cycle

D = Vout / Vin

Inductor Ripple

ΔIL = ripple% × Iout

Inductance

L = (Vin − Vout) × D / (ΔIL × fSW)

Output Capacitance

C = ΔIL / (8 × fSW × ΔVout)
